# Cardo – your pivot point ⊕

A freely arrangeable, **local-first dashboard** for macOS, Linux and Windows: to-dos, notes,
calendar, timers and more – as widgets on your personal board. No account, no cloud, no tracking.

- **Website & docs:** https://hollatzleif.github.io/cardo-app/
- **Download:** [latest release](https://github.com/hollatzleif/cardo-app/releases/latest) or
  `curl -fsSL https://hollatzleif.github.io/cardo-app/install.sh | sh`
- **Forum:** [GitHub Discussions](https://github.com/hollatzleif/cardo-app/discussions) – questions, feedback, ideas

This repository hosts Cardo's **releases, website and community forum**.
The source code lives in a private repository; installers here are built and signed by its CI.
