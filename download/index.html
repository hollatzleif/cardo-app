Download Cardo

Free, no account, no strings attached. Pick your platform – or use the one-line install command, which detects your OS and fetches the latest release from GitHub.

All installers are published on GitHub Releases, so you can always verify exactly what you are downloading.

🍎 macOS

Download the .dmg from GitHub Releases, or install from the terminal:

Terminal 
curl -fsSL https://hollatzleif.github.io/cardo-app/install.sh | sh
“Cardo can't be opened because it is from an unidentified developer”?

That's expected, and here's the honest reason: Apple charges 99 €/year for a signing certificate, and Cardo is a free, donation-funded app. We'll buy the certificate as soon as donations cover it. Until then, macOS shows this warning for every unsigned app.

  1. Find Cardo.app in your Applications folder.
  2. Right-click (or Ctrl-click) it and choose Open.
  3. In the dialog, click Open again. macOS remembers your choice – this is only needed once.

🪟 Windows

Download the .msi from GitHub Releases, or install from PowerShell:

PowerShell 
irm https://hollatzleif.github.io/cardo-app/install.ps1 | iex
Windows SmartScreen says “Windows protected your PC”?

Also expected: Windows shows this for installers without a paid code-signing certificate. Cardo will get one once donations cover the cost – we'd rather be honest about a warning than quietly pass the bill on to you.

  1. In the SmartScreen dialog, click More info.
  2. Then click Run anyway.

🐧 Linux

Download the .AppImage or .deb from GitHub Releases, or install from the terminal:

Terminal 
curl -fsSL https://hollatzleif.github.io/cardo-app/install.sh | sh
Using the .AppImage directly?
  1. Make it executable: chmod +x Cardo.AppImage
  2. Run it: ./Cardo.AppImage

On Debian/Ubuntu the .deb package integrates with your app menu. The builds are unsigned for the same reason as on macOS and Windows: signing costs money, and Cardo is donation-funded. Certificates come once donations cover them.

After installing

Open Cardo and you're done – no database to set up, no account to create. If you want a quick tour of your first dashboard, head over to the docs.

Cardo is local-first: your data stays on your device. No account, no tracking – this website sets no cookies either.
