Assistant

It proposes. You decide.

Dump your thoughts in and get back proposal cards — appointments, to-dos, notes, habits. Nothing is applied until you say yes. The model runs on your device; or bring your own Claude subscription if you want cloud power.

Give an assistant a personality, working style and memory. Run several of them, put them in a team, let them delegate to each other.

Which model should I pick?

Roughly: more RAM buys a bigger model, and a bigger model understands more but answers slower. Cardo shows what fits your machine before you download anything.

  • 8 GB RAM — a 3–4 B model, quick and fine for braindumps.
  • 16 GB — 7–8 B, noticeably better at German and at longer texts.
  • 32 GB and up — 12–14 B, or use Claude and keep the RAM.

Apple Silicon is markedly faster than an equivalent Intel machine, because the model shares memory with the GPU.

Is anything sent to a server?

With a local model: no. The only network access is the one-time model download from huggingface.co, and it only happens when you press install.

With Claude: yes — your prompt goes to Anthropic through the Claude Code CLI you installed and logged into yourself. Cardo marks that clearly, and it is never the default.

Teams and delegation

Several assistants can share a chat. A router decides who answers, and one can hand a question to another that knows the subject better. Each keeps its own memory and competences.

Download

Free, no account, no strings attached.

Installers for all three platforms are published on GitHub Releases. The one-liner detects your system and fetches the latest one.

macOS and Linux

Terminal 
curl -fsSL https://hollatzleif.github.io/cardo-app/install.sh | sh

Windows

PowerShell 
irm https://hollatzleif.github.io/cardo-app/install.ps1 | iex
macOS says the app is damaged or from an unidentified developer

The builds are not notarised yet. Right-click the app in Finder and choose Open, then confirm once — after that it starts normally. Or run xattr -dr com.apple.quarantine /Applications/Cardo.app.

Windows SmartScreen warns about an unknown publisher

Same reason: no paid code-signing certificate. Click More info and then Run anyway. The installer is the file published on GitHub Releases and nothing else.

Getting started

From installed to “this is my place now”.

  1. Say hi. The first start drops you on an empty board. Nothing to configure, no account, no wizard.
  2. Press ⌘E (or Ctrl E) for edit mode. Now widgets get a title bar with a drag grip and a resize corner.
  3. Add widgets from the tool market, place them, resize them. Keep separate pages for work, home and focus.
  4. Press ⌘K for the command palette — every command in the app, one keystroke away.
  5. Make it yours in the design panel: theme, card style, font, density, per-widget accents.
  6. Run the self-test in the settings whenever something feels off.
Where is my data?

In an SQLite database in your user folder, plus your notes as plain .md files in a folder you picked yourself. Both readable with any other tool. There is no server holding a copy.
